# GIFLIF Instagram cover hosting

Public host for approved GIFLIF Reel cover images only, so Meta's Graph API
can fetch a `cover_url` when creating a new Reel container (Instagram
requires a publicly-accessible HTTPS URL for this parameter — it cannot
accept a file upload or an authenticated URL).

No code, no credentials, no schedule data, no captions, no videos —
only the exact approved cover artwork, unmodified.
